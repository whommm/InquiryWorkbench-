# SmartProcure 前端 UI/UX 优化设计方案

## 1. 核心设计理念

*   **沉浸式协作**：打造“人与 AI 共同编辑表格”的沉浸感，而非割裂的“左边聊天、右边看表”。
*   **现代极简**：采用清爽的无边框/轻边框设计，利用阴影和间距构建层级，减少视觉噪音。
*   **内容为王**：最大化表格（工作区）的可视面积，同时保证 AI 助手（Copilot）随时触手可及。

---

## 2. 布局重构方案

目前的布局是简单的左右分割，建议升级为经典的 **"Header + Sidebar + Main"** 结构。

### 2.1 全局 Header (顶部导航栏)
*   **高度**：48px - 56px
*   **背景**：白色 (bg-white) 或极浅灰，底部带轻微边框。
*   **内容规划**：
    *   **左侧**：Logo + 应用名称 (SmartProcure) + 面包屑导航。
    *   **中间**：当前询价单标题（支持点击重命名）、自动保存状态指示器。
    *   **右侧**：
        *   **视图切换**：[表格模式] / [看板模式] / [分析报告]
        *   **全局操作**：导出、分享、设置。
        *   **用户头像**：个人中心入口。

### 2.2 智能侧边栏 (ChatPanel 升级)
*   **定位**：不仅仅是聊天窗口，而是“智能副驾驶 (Copilot)”。
*   **宽度优化**：
    *   默认：400px（保证阅读体验）。
    *   最大：600px（展示复杂图表或长文时）。
    *   **折叠模式**：折叠后保留一条 48px 宽的工具条，显示 AI 状态图标，点击可快速展开。
*   **视觉升级**：
    *   移除厚重的右侧边框，改用 `shadow-xl` 悬浮感阴影，或者极细的 `border-r border-gray-100`。
    *   背景色采用半透明模糊效果 (Backdrop Blur) 增加现代感。

### 2.3 主工作区 (UniverSheet)
*   **布局**：占据剩余所有空间。
*   **优化**：
    *   表格顶部增加 **Toolbar**（工具栏），放置筛选、排序、批量操作等高频功能。
    *   表格与其容器之间增加适当的 `padding` 和圆角，使其看起来像一张“浮在桌面上”的纸，而不是嵌在屏幕里的网格。

## 3. 关键组件样式升级

### 3.1 对话面板 (ChatPanel)
*   **消息气泡**：
    *   **用户**：右侧对齐，品牌色背景（如 Emerald-500），白字，圆角矩形。
    *   **AI**：左侧对齐，灰背景（Gray-100），黑字。支持 Markdown 渲染。
    *   **思考状态**：展示动态的“思考中...”动画，增加 AI 的灵动感。
*   **输入框 (Input Area)**：
    *   **悬浮设计**：不再是固定在底部的长条，而是悬浮在底部的圆角卡片（类似 ChatGPT 或 Claude 的输入框）。
    *   **功能增强**：
        *   支持多行输入（自动增高）。
        *   左侧：附件上传按钮 (+)
        *   右侧：发送按钮（带 Loading 状态）。
        *   支持 `/` 快捷指令（如 `/clear` 清空, `/export` 导出）。

### 3.2 推荐面板 (RecommendPanel) & 供应商面板 (SupplierPanel)
*   **卡片化**：将列表项改为独立的卡片，增加 `hover` 浮起效果。
*   **信息分层**：
    *   一级信息（公司名、推荐分）：加粗、大字号。
    *   二级信息（联系人、电话）：灰色、小字号。
    *   标签（Tag）：使用不同颜色的胶囊样式（如“现货”用绿色，“需订货”用橙色）。

---

## 4. 交互体验 (UX) 优化

### 4.1 响应式设计
*   **移动端适配**：
    *   屏幕宽度 < 768px 时，侧边栏自动隐藏。
    *   点击 Header 上的“AI”图标，侧边栏以 **抽屉 (Drawer)** 形式从右侧滑出，覆盖在表格上方。

### 4.2 动效 (Animation)
*   **侧边栏展开/折叠**：使用 `transition-all duration-300 ease-in-out` 实现丝滑过渡。
*   **消息上屏**：AI 回复时，文字逐字显示（打字机效果），减少用户等待焦虑。
*   **列表加载**：使用骨架屏 (Skeleton) 代替简单的 Loading 转圈。

### 4.3 快捷键支持
*   `Cmd/Ctrl + B`：切换侧边栏折叠/展开。
*   `Cmd/Ctrl + K`：唤起全局命令搜索。
*   `Cmd/Ctrl + Enter`：发送消息。

---

## 5. 色彩系统建议 (基于 Tailwind)

*   **主色 (Primary)**: `Emerald-600` (专业、稳重、与“采购/金钱”相关)
*   **辅助色 (Secondary)**: `Slate-600` (用于文字、图标)
*   **背景色 (Background)**: `Gray-50` (应用背景), `White` (卡片背景)
*   **警示色 (Warning)**: `Amber-500`
*   **错误色 (Error)**: `Rose-500`

---

## 6. 实施路线图

1.  **Phase 1 (结构重构)**：
    *   引入 `Header` 组件。
    *   重构 `Layout` 为 `Header - Sidebar - Main` 结构。
2.  **Phase 2 (样式升级)**：
    *   美化 `ChatPanel` 和输入框。
    *   优化 `UniverSheet` 容器样式。
3.  **Phase 3 (细节打磨)**：
    *   添加动效、骨架屏。
    *   适配移动端响应式。
